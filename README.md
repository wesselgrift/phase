# phase.

A calm, private period tracker with daily check-ins and hormone-based insights, styled after the Stoic app.

- One file: `index.html`. No build step, no server, no account.
- Data stays in the browser (`localStorage`). Use Settings → Export backup to keep a copy.

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://127.0.0.1:8765. On iPhone, host it anywhere static and use "Add to Home Screen" so Safari keeps the data.

Not medical advice. Predictions are estimates and are not birth control.
